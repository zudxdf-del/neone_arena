# NEON ARENA 2.0 — LAN / Direct

Режим подключения сделан по принципу Minecraft Java: один игрок запускает игру на сервере, второй подключается к тому же адресу.

## Игра по Wi‑Fi или хотспоту

1. На устройстве 1 запусти `node server/server.js`.
2. Сервер покажет адрес вида `http://10.x.x.x:8080`.
3. Открой этот адрес на устройстве 1 и нажми **Создать игру**.
4. На устройстве 2 открой тот же адрес и нажми **Подключиться**.
5. После второго игрока матч стартует автоматически.

## Интернет

Если Node-сервер размещён на публичном сервере, оба игрока могут открыть его публичный адрес. Для HTTPS-сайта нужен `wss://` для WebSocket; обычно это делается через Nginx + TLS.

## Важно для мобильного интернета

Прямое подключение к телефону по его мобильному IP обычно невозможно из-за NAT оператора. Для игры между разными мобильными сетями нужен публичный сервер/VPS либо отдельная P2P/WebRTC-схема с сигнализацией.
